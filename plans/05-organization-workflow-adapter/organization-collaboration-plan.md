# 组织协作计划

## 目标

把 Legion 的交互模型从“调用 AI”升级为“管理智能体团队”。

## 实施内容

| 能力 | 交付 |
|------|------|
| 公司模型 | company、department、team、agent 四级组织 |
| 汇报关系 | 单上级汇报链、任务升级、逐级委派 |
| 动态组队 | 项目组成员、目标、预算、解散策略 |
| 角色模板 | CEO/CTO/PM/Developer/Tester/Designer/Ops/Data 等 |
| 能力声明 | inputs、outputs、authority、budget、model_policy |
| 通讯机制 | 委派、上报、@提及、广播、数据管道 |
| 数据共享 | 全局知识、部门数据、项目数据、任务数据、私有记忆 |

## 验收

- Agent 权限由组织位置和能力声明共同决定。
- 每个任务携带目标传导链。
- 通讯记录可审计。
- 多公司数据隔离不可绕过。
