# 典型应用场景落地计划

## 场景顺序

| 顺序 | 场景 | P6 交付级别 | 原因 | MVP |
|------|------|-------------|------|-----|
| 1 | 智能体软件开发团队 | full template | 最贴近现有代码与工具能力，适合作为首个标杆闭环 | CTO → Developer → Tester → Reviewer |
| 2 | 游戏内容开发业务智能体 | skeletal template | 多工种强协作，适合作为第二标杆候选 | Producer → Design/Art/Code/QA/Ops |
| 3 | 内容生产工厂 | skeletal template | 工作流清晰，质量门控明显 | 选题 → 写作 → 校审 → 发布 |
| 4 | 智能客服团队 | skeletal template | 持续运行和知识库价值明显 | 客服 Agent + 质检 Agent + Know |
| 5 | 数据分析部门 | skeletal template | 数据管道和报告沉淀明显 | 采集 → 清洗 → 分析 → 报告 |

## 模板交付

`full template` 交付：

- 组织模板。
- 角色模板。
- 工作流 DSL。
- 预算策略。
- 知识库模板。
- 审批门控配置。
- 监控看板指标。

`skeletal template` 只交付：

- 组织骨架。
- 核心角色清单。
- 主工作流 DSL 草案。
- 预算策略草案。
- 知识域清单。
